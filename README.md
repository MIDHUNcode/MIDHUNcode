### 🚚 FleetDash — Real-Time Fleet Telemetry Dashboard

A high-throughput **MERN Stack real-time fleet monitoring system** designed to handle telemetry from thousands of vehicles.

**Tech:** React + TypeScript • Node.js • Express • MongoDB • Redis • Socket.IO • Worker Threads • k6

**Key Features**

* 📡 Real-time vehicle telemetry
* 🔴 Redis Pub/Sub for real-time messaging
* ⚡ Socket.IO live updates
* 🗄️ MongoDB Bucket Pattern for telemetry storage
* 🧵 Node.js Worker Threads for high-throughput processing
* 📊 Fleet analytics dashboard
* 🗺️ Real-time vehicle visualization
* 🚀 Performance testing with k6
